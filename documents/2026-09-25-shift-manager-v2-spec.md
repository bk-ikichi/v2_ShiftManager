# シフト管理アプリ v2 仕様書

作成日：2026-09-25
作成経緯：mattpocock-skills:grilling によるヒアリングセッションの結果をまとめたもの

## 背景・目的

- 現状、確定シフトはLINEグループに1日ずつ写真またはPDFで送られてきており、見落としや時間の読み間違いが発生している
- シフト希望の提出はGoogleFormで行っている
- 本アプリで「シフト希望の申請」と「確定シフトの閲覧」を一元化し、上記の問題を解消する
- v1（`../ShiftManager`）とは別物として扱い、v1の仕様は引き継がない。v1はスコープ過大で完成が見えなかったため、v2は最小構成で確実に運用に乗せることを優先する

## 前提

| 項目 | 決定内容 |
|---|---|
| 店舗 | 1店舗専用。店舗の概念はデータに持たない |
| ロール | 管理者・スタッフの2種。実体は「スタッフ＋管理権限フラグ」。管理者も出勤者としてシフトに載る。管理者は複数人可・権限は同一 |
| 確定シフトの作成 | 外部（本部）システムで作成し、管理者が本アプリへ転記する |
| 通知 | 行わない（アプリ内表示のみ） |
| 利用端末 | スタッフ：スマートフォン優先 / 管理者：PC（転記）＋スマートフォン |
| 時刻 | 8:00〜23:00、30分刻み。日またぎ勤務なし（IN < OUT） |

## 技術スタック

- Java + Spring Framework + Spring Security（セッション認証、remember-me）
- MyBatis
- Thymeleaf + Tailwind CSS（必要箇所のみ少量のJavaScript）
- PostgreSQL（Neon）
- Docker
- デプロイ先：未確定（Renderが候補。無料プランはスリープ後の起動待ちが発生する点に留意）

## アカウント

- スタッフは管理者が登録する。登録項目：名前、ログインID、初期パスワード、初期ポジション、管理者権限の有無、有効/無効
- 初期パスワードは入力を省略でき、省略した場合は全スタッフ共通の固定値を使う。固定値は環境変数 `STAFF_INITIAL_PASSWORD` で指定し、未設定またはパスワードのルールに合わない場合はアプリを起動しない（本番運用前の一括登録の手間を減らすため）
- 初回ログイン時にパスワード変更を必須とする
- パスワードを忘れた場合は、管理者が仮パスワードにリセットし、次回ログイン時に変更させる（メール送信は行わない）
  - 仮パスワードはシステムがランダムに生成する（英小文字と数字の8文字。読み間違えやすい `0` `o` `1` `l` `i` は使わない）。リセット直後の画面に1回だけ表示し、再表示はできない
- 退職者は削除せず無効化する（ログイン不可、過去のシフトは保持）
- 最初の管理者アカウントは name:`admin` / pw:`admin` で作成する（初回ログイン時のパスワード変更必須を適用する）
- ログイン状態の保持：チェック時10日間（remember-me）
- 共通機能：ログイン、ログアウト、パスワード変更

## シフト希望の申請（スタッフ）

### サイクルと締切

- サイクルは毎月1日・11日・21日で区切る（21日〜月末は月の日数により8〜11日）
- 締切はサイクル開始日の5日前（管理者が設定変更可能。初期値5日）
- 締切を過ぎたサイクルはスタッフ側から編集不可。それ以降のサイクルは自由に編集できる
- 締切後の変更は口頭で伝え、管理者が代理で編集する

### 入力画面

- 翌々月の末日まで申請できる（例：9/25時点なら9月・10月・11月）
- 1か月ごとに1ページ表示し、1行1日で縦に並べる。サイクルごとに見出しと締切日を表示する
- 各行：日付 / パターン / IN / OUT / 備考
  - パターンを選ぶとIN/OUTが自動入力される（その後の手修正は可）
  - IN/OUTはプルダウン
  - 1日1時間帯のみ。例外は備考に記載する
- 締切済みサイクルの行は灰色表示・編集不可
- 保存ボタンは画面下部固定の「登録する」1つのみ（ページ内を一括保存）
- 月を切り替える際、未保存の入力があれば確認を出す
- サイクルごとに「この期間は出勤できない」チェックを置く

### 提出済みの判定

- 「そのサイクル内に1日以上の申請がある」または「この期間は出勤できない」がチェックされている場合、提出済みとする
- 管理者が代理入力した場合も提出済みとして扱う

### パターン

- スタッフが自分用のパターン（名前、IN、OUT）を作成・編集・削除できる。本人のみ使用する
- 管理画面はマイページ内に置く

## 確定シフトの転記（管理者）

### 画面構成

```
< ○日 | ○日 | ○日 >        [この日を公開] [○日〜○日まで公開]

(ポジションA)
+------+-------+-------+--------+---------+------+
| 名前 | IN    | OUT   | 申請IN | 申請OUT | 備考 |
+------+-------+-------+--------+---------+------+
| aaaa | 08:00 | 17:00 |  08:00 |  18:00  |      |
+------+-------+-------+--------+---------+------+
| + 追加する                                      |

(ポジションB)
...
```

- 1日単位の画面。前後の日付へ移動できる
- ポジションの表示順でグループ分けする
- 入力はすべてプルダウン
- 名前の候補：そのポジションを初期ポジションとするスタッフを先頭に、その下に他のスタッフも選択可能
- シフトごとに「どのポジション枠に入れたか」を保存する（スタッフの初期ポジションは候補の並び順に使う）
- 同一日に同一スタッフを二重に選択できない（サーバー側でも検証）
- 名前を選ぶと申請IN/申請OUTを読み取り専用で表示する。申請がない場合は「--:--」
- 申請の備考は「備考」列に常に表示する
- 申請の時間帯と異なる時間、または申請のない日に入力した場合は、名前の真下に警告を表示する（登録は可能）
- 各行の右端に、8:00〜23:00の時間軸上でIN〜OUTを表すミニバーを表示する。色は、管理者なら緑（社員）、それ以外はその行のポジションの色。名前・IN・OUTを変えるとその場で描き直す。名前・IN・OUTのどれかが未選択、またはIN ≥ OUTの行には出さない（2026-10-02 追加）

### 行の扱い

- 未入力の日を開いたとき、ポジションごとに空欄行を6行表示する
- 「+ 追加する」で行を追加できる
- 「登録する」で、各ポジション内をINの早い順に並べ替え、空欄行は削除する
- 登録済みの日を開き直したときは、登録済みの行のみ表示する（追加は「+ 追加する」）

### 公開

- 下書きと公開を分ける。公開済みの日のみスタッフに表示される
- 公開ボタンは2つ
  - 「この日を公開」
  - 「○日〜○日まで公開」：開始日・終了日をプルダウンで選ぶ。初期値は表示中の日を含むサイクルの初日〜末日
- 公開済みの日を編集して登録した場合、即座にスタッフへ反映する。登録前に「公開済みの日です。変更はすぐスタッフに表示されます」と確認を出す
- 公開後の変更（時刻変更・追加・取り消し）があったスタッフには「変更あり」の印を付ける

## 申請の閲覧（管理者）

- サイクルを選択し、「日付 × スタッフ」の表で全員の申請（IN/OUT/備考）を表示する（PC前提）
- 未提出者は行の背景色を変える
- マスをクリックしてIN/OUT/備考を代理編集できる（締切後も可）

## シフトの閲覧（スタッフ）

### トップ画面

上から順に以下を表示する。

1. 「変更あり」のシフト（時刻変更・追加・取り消し）。本人が「確認済み」を押すまで表示し続ける。取り消しの場合は「この日のシフトは取り消されました」と表示する
2. 次回の出勤
3. 月カレンダー（日曜始まり）。本人の出勤日はINの時刻を表示して色付きにする。公開済みの日を押すとその日の日別シフト一覧を開く。未公開の日は押せない。前後の月へ移動できる（2026-09-28 変更。当初は「直近の出勤一覧」）
4. 申請締切の案内（未提出なら強調表示）
5. 今月・来月の勤務予定時間の合計（公開済みシフトの OUT − IN の合計。休憩は管理しないため拘束時間）

- カレンダーで表示できる月は、スタッフは先月〜2か月後、管理者は過去を制限せず2か月後まで（2026-09-28 追加）

### 日別シフト一覧

- 公開済みの日について、全員分（名前、ポジション、IN/OUT）を表示する
- ポジション別にグループ分けし、各グループ内はINの早い順
- スタッフが閲覧できる過ぎた日は前月1日以降（例：9月なら8/1以降）。それより前はスタッフの画面から非表示にする（データは削除しない。管理者は過去分も閲覧可能）（2026-09-28 変更。当初は1週間）
- スタッフが閲覧できる先の日は公開済みの最後の日まで。それより先の日は「閲覧可能なシフトはありません」と表示し、次の日へ移動できない。途中の未公開の日は「この日のシフトはまだ公開されていません」と表示する（管理者は制限しない）（2026-09-28 追加）
- ガントチャートで表示する。左に名前、右に8:00〜23:00の時間軸（1時間おきに数字と縦線）を置き、ポジションの間に横線を引いて、IN〜OUTを横バーで表す。バーの色は、管理者なら緑（社員）、それ以外は入れたポジションの色。時刻はバーの中に書き、スマホ幅（640px未満）では5時間未満の勤務だけバーの外（OUTが19:00以前なら右、それより後なら左）に書く。上部に凡例（その日のポジションの色と、管理者がいれば社員）を置く（2026-10-02 追加）

## ポジション管理（管理者）

- 名前と表示順（転記画面・日別一覧で上から並ぶ順）を持つ
- 追加・編集・並び替えができる
- スタッフまたはシフトで使用中のポジションは削除不可。「非表示」のみ可能
- 色を持つ。水色・ピンク・赤・オレンジ・黄・紫・青・グレーから選ぶ（初期値グレー）。転記画面・日別一覧のバーの色に使う。管理者は色に関係なく緑（社員）で表示するため、緑は選択肢に入れない（2026-10-02 追加）

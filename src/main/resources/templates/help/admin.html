1. 最初にやること

アプリを使い始めるときは、次の順で準備します。

  1. ログインID admin、パスワード admin でログインし、表示されたパスワード変更画面で新しいパスワードに変えます（最初の1回だけ）。
  2. ポジションを登録します（ポジション管理）。
  3. スタッフを登録します（スタッフ管理）。自分以外の管理者も、「管理者権限を付ける」にチェックを入れてここで登録します。
  4. 申請の締切日数を確認します（設定）。初期値は「サイクル開始日の5日前」です。
  5. スタッフにログインIDと初期パスワードを伝え、スタッフ向けの使い方（PDF）を渡します。

最初の管理者の名前は「管理者」になっています。スタッフ管理の「編集」で自分の名前に変えてください。管理者もスタッフと同じようにシフトに載り、申請もできます。

管理者のメニューには、スタッフのメニューに加えて「転記」「申請一覧」「スタッフ」「ポジション」「設定」が表示されます。

2. ポジション管理

メニューの「ポジション」で、キッチンやカウンターなどの持ち場を登録します。

  • 名前：転記画面と日別シフト一覧の見出しになります。
  • 表示順：小さいものから、転記画面と日別シフト一覧の上に並びます。
  • 色：転記画面と日別シフト一覧の帯の色です。水色・ピンク・赤・オレンジ・黄・紫・青・グレーから選びます。管理者は色に関係なく緑（社員）で表示されます。
  1. 追加するときは、下の「追加」に名前・表示順・色を入れて「追加する」を押します。
  2. 変えるときは、その行を直して「保存」を押します。

スタッフやシフトで使われているポジションは削除できません。使わなくなったら「非表示」にチェックを入れて保存してください。

3. スタッフ管理

メニューの「スタッフ」で、スタッフ（管理者を含む）の登録・編集・無効化を行います。

登録する

  1. 「スタッフを登録する」を押します。
  2. 名前、ログインID（半角英数字と . _ - の3〜50文字）、ポジションを入力します。
  3. 初期パスワードを入力します。空欄にすると、全スタッフ共通の初期パスワードになります（値はアプリの設定で決めてあります。わからない場合はアプリを設置した担当者に確認してください）。
  4. 管理者にする場合は「管理者権限を付ける」にチェックを入れます。
  5. 「登録する」を押します。

スタッフは初めてログインしたときに、自分でパスワードを変更します。ポジションは、転記画面で名前の候補を並べる順番に使われます（そのポジションのスタッフが候補の上に出ます）。

編集する・パスワードをリセットする

一覧の「編集」で、名前・ログインID・ポジション・管理者権限を変えられます。自分の管理者権限は外せません。

スタッフがパスワードを忘れたときは、編集画面の「パスワードのリセット」で「リセットする」を押します。表示された仮パスワードを本人に伝えてください。本人は次にログインしたとき、新しいパスワードに変更します。

仮パスワードはリセットした直後の画面にしか表示されません。わからなくなった場合は、もう一度リセットしてください。

退職したとき

一覧の「無効にする」を押します。無効にしたスタッフはログインできなくなりますが、過去のシフトは残ります。戻すときは「有効にする」を押します。スタッフは削除できません。自分自身は無効にできません。

4. 申請の確認

メニューの「申請一覧」で、サイクルごとに全員のシフト希望を「スタッフ × 日付」の表で見られます。PCでの利用を想定しています。

  • 「< 前」「次 >」でサイクルを切り替えます。そのサイクルの締切日も表示されます。
  • まだ提出していないスタッフは、行の色が変わります。
  • 「この期間は出勤できない」にしたスタッフは、その旨が表示されます。
  • 備考があるマスには印が付きます。押すと備考が表示されます。
  • 日付を押すと、その日の転記画面が開きます。
  • 名前をドラッグすると、行を並び替えられます。並び順は保存されます。
  • 「Excel用にコピー」を押すと、時刻だけをコピーできます（1日につきIN・OUTの2列、申請のない日は空欄）。Excelなどにそのまま貼り付けられます。

代わりに申請を直す

  1. 表のマスを押します。
  2. IN・OUT・備考を入れて「保存する」を押します。申請を取り消すときは「この日の申請を削除する」を押します。

締切後でも保存できます。締切後の変更は、スタッフから直接聞いてここで直してください。「この期間は出勤できない」にしている期間に保存すると、そのチェックは外れます。

5. シフトの転記

本部のシステムで作った確定シフトを、メニューの「転記」で1日ずつこのアプリに写します。

  1. 上の日付で、転記する日を選びます。
  2. 各ポジションの表で「名前」を選びます。そのポジションのスタッフが候補の上に並びます（ほかのポジションのスタッフも選べます）。同じ日に同じスタッフは1回しか選べません。
  3. IN・OUTを選びます。名前を選ぶと、その人の申請IN・申請OUT・備考が表示されるので、見比べながら入力できます。
  4. 行が足りなければ「+ 追加する」を押します。行を空にするには「クリア」を押します。
  5. 「登録する」を押します。ポジションの中は出勤の早い順に並び替えられ、空の行は消えます。
  • まだ登録していない日を開くと、ポジションごとに空の行が6行表示されます。登録済みの日は、登録した行だけが表示されます。
  • 各行の右端の帯は、8時〜23時のうちIN〜OUTの時間を表します。色はポジションの色、管理者は緑です。

警告が出たとき

申請と違う時間を入れたときや、申請がない日に入れたときは、名前の下に警告が表示されます。確認のための表示なので、そのまま登録できます。

希望シフトを反映する

「希望シフトを反映する」を押すと、まだどの行にも入っていないスタッフの申請を、そのスタッフのポジションの空いている行に入れます。入力済みのスタッフはそのままです。必要に応じて直してから「登録する」で保存してください。

登録しただけでは、スタッフには表示されません。次の「公開」が必要です。

6. 公開

登録した内容は下書きです。公開した日だけがスタッフに表示されます。転記画面の日付の横に「公開済み」か「下書き」が表示されます。

  • 「この日を公開」：表示している日を公開します。
  • 期間を選んで「まで公開」：開始日と終了日を選んで、その間の日をまとめて公開します。初期値は、表示している日を含むサイクルの初日〜末日です。

公開されるのは登録済みの内容です。シフトが登録されていない日は公開されません。

公開した後に直すとき

公開済みの日を直して「登録する」を押すと、確認のあと、すぐにスタッフに表示されます。時間の変更・追加・取り消しがあったスタッフのトップ画面には「変更あり」が表示されます（本人が「確認済み」を押すまで）。

メニューの「シフト」（日別シフト一覧）では、管理者には「この日を転記画面で開く」が表示されます。管理者は過去の日も制限なく見られます。

7. 設定

メニューの「設定」で、申請の締切を「サイクル開始日の何日前にするか」（0〜30日）を決めます。たとえば5日前なら、11日〜20日分の締切は6日です。入力して「保存する」を押します。

8. 困ったとき

スタッフがパスワードを忘れた

スタッフ管理の「編集」でパスワードをリセットし、仮パスワードを本人に伝えてください。

自分（管理者）がパスワードを忘れた

ほかの管理者にリセットしてもらってください。管理者が1人だけだとリセットできる人がいなくなるため、管理者は2人以上登録しておくことをおすすめします。

スタッフが退職した

スタッフ管理で「無効にする」を押してください。

スタッフから「シフトが見られない」と言われた

転記画面でその日が「下書き」のままになっていないか確認し、公開してください。

締切後に申請を変えたいと言われた

申請一覧でマスを押して、代わりに直してください。

ポジションを削除できない

スタッフかシフトで使われているためです。「非表示」にしてください。
